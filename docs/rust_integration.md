# Rust Reference Crate (`slm_os_integration/`)

A standalone Rust crate that ports the simulator's eviction policies for
direct integration into the SLM-OS runtime. The crate is intended as a
drop-in template for `runtime/src/mm/` in the SLM-OS repo — it has no
external dependencies and the public API is small enough to read in one
sitting.

## Layout

```
slm_os_integration/
├── Cargo.toml
├── src/
│   ├── lib.rs              # Re-exports
│   ├── block.rs            # BlockMeta, BlockFeatures, PoolType
│   ├── eviction_policy.rs  # The trait every policy implements
│   ├── lru.rs              # LRU
│   ├── lfu.rs              # LFU (ties broken by LRU)
│   ├── slm_heuristic.rs    # Hand-tuned priority cascade
│   └── cacheus.rs          # Adaptive weighted-ensemble selector
└── tests/
    └── parity.rs           # 11 tests; each mirrors a Python policy test
```

## The Contract

```rust
pub trait EvictionPolicy {
    fn select_victim(&mut self, candidates: &[BlockMeta]) -> usize;
    fn score(&mut self, candidates: &[BlockMeta]) -> Vec<f32> { ... }
    fn update_feedback(&mut self, block_id: u32, was_fault: bool) { ... }
    fn reset(&mut self) {}
    fn name(&self) -> &'static str;
}
```

`select_victim` returns the *index* into `candidates`. `score` is what
CACHEUS calls to combine experts. `update_feedback` is how the runtime
tells an adaptive policy whether a previous eviction was good
(`was_fault=false`, the evicted content was not re-accessed within the
window) or bad (`was_fault=true`).

## CACHEUS Recommended Config

The Phase 5 sweep (see `data/results/RESULTS.md`) found:

| Pool | Mean normalized fault rate |
|------|----------------------------|
| **`ml_only` (XGBoost + MLP)** | **0.212** |
| `all_5` (LRU + LFU + ARC + ML) | 0.427 |
| `ml_plus_lru` | 0.465 |
| `classical_only` | 0.857 |

Adding classical experts to the ensemble *hurts* — their LRU-level
scores pull the weighted decision back toward LRU. The recommended
runtime config is `lr=0.4, window=200, pool=ml_only`.

## Pulling in the Trained Models

The XGBoost and MLP code is generated by:

```bash
python scripts/export_to_slmos.py \
    --xgb-model data/models/xgb_model.json \
    --mlp-model data/models/mlp_model.pt \
    --output-dir slm_os_integration/src/generated/
```

Then enable the `generated_models` cargo feature:

```bash
cd slm_os_integration && cargo build --features generated_models
```

End-to-end Python ↔ Rust agreement is verified by
`scripts/verify_rust_export.py` — XGBoost matches byte-perfect, MLP int8
agrees with Python on ≥95% of synthetic 8-candidate eviction groups.

## Running the Tests

```bash
cd slm_os_integration && cargo test
```

11 parity tests pass — each mirrors one of the Python tests in
`tests/test_policies.py` or `tests/test_cacheus.py` and verifies the
Rust port produces the same eviction decision.
